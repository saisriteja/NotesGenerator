## [2026-09-16] Update 7 — P1 granular teaching prompts (first-principles + papers)

**How it works:** LLM writes granular content on first pass, not post-hoc summarization. Papers injected into every topic + prerequisites + roadmap.

## [2026-09-16] Update 8 — Shared-GPU VRAM auto-clamp

**Problem:** vLLM failed on GPU 0 when other jobs held ~25 GiB: `Free memory (69.64 GiB) < desired utilization (0.82 → 77.88 GiB)`.

**Solution:** Added `clamp_gpu_mem_for_free_vram()` in `gpu_defaults.py`; `05_09_vlm_runner.py` calls it before loading the model. On a shared GPU, util is lowered to `free/total` (e.g. 0.82 → ~0.70). On an empty GPU, Colab defaults unchanged. Fails fast with a clear message if free VRAM &lt; ~12 GiB.

**Workaround for this machine:** GPU 0 often ~95 GiB used by other Python jobs; use `export CUDA_VISIBLE_DEVICES=1` (~85 GiB free) for report regeneration.

**Test result:** GPU 0 with only 2.7 GiB free → clear exit message. Regeneration started on GPU 1.

## [2026-09-16] Update 10 — Report timestamp format + truncation artifacts

**Problem:** Segment headings used raw seconds (`3623.053–3800.296`) instead of `01:00:23–01:03:20`. Paper context truncation marker `[truncated for context limit]` leaked into report body.

**Solution:** `enrich_segments` adds `segment_time`; prompts require MM:SS format; `normalize_segment_timestamps()` post-processes headings/revisit lines; `fit_prompt()` truncates silently (no copyable marker); `strip_miss_sections()` removes any leaked markers.

## [2026-09-16] Update 11 — Repetition-loop sanitization + final audit pass

**Problem:** `prerequisites.md` (and merged `report.md`) contained hundreds of repeated `We will not assume you’ve ever seen a "multi-LLM" system.` sentences — an LLM degeneration loop triggered by the “know NOTHING” prerequisites prompt.

**Solution:**
- Rewrote `PREREQUISITES_PROMPT` to require structured `###` bullet trees and explicitly forbid disclaimer spam / repeated sentences.
- Added `sanitize_generated_markdown()` — strips assumption-list loops, tail phrase repetition, duplicate lines, and dangling cut-off fragments.
- Added `audit_report_block()` + `sanitize_report_blocks()` — runs on prerequisites, roadmap, all `topic_*.md`, and merged `report.md` at end of generation and on `--merge-only`.
- Anti-repetition rules added to `LEARNING_ROADMAP_PROMPT`, `TOPIC_DETAIL_PROMPT`, and `REFINE_TOPIC_PROMPT`.

**Clean existing run (no VLM):** `python .../09_generate_report.py --run-dir runs/lecture_2_test --merge-only`

**Regenerate prerequisites (needs VLM):** `05_09_vlm_runner.py --run-dir runs/lecture_2_test --force-topics`

## [2026-09-16] Update 13 — vLLM parallel batching for report generation

**Opportunity:** Slide captioning already used `generate_batch`; report steps ran outline windows and topics one-by-one.

**Solution:** vLLM continuous batching (not Python threads — one engine, multiple prompts per `generate` call):
- `generate_batch_chunked()` in `qwen_vllm.py` with optional per-call `max_tokens`
- Outline windows batched (`--outline-batch-size`, default 4)
- Roadmap + prerequisites batched together in one call
- Topic write + each refine pass batched across topics (`--topic-batch-size`, default 2)
- Regenerate-during-verify uses the same batching

**On large GPUs (e.g. RTX PRO 6000):** try `--topic-batch-size 3` or `4`. Lower if OOM.

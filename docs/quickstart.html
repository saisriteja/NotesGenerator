Quickstart

Run NotesGenerator in Google Colab (recommended) or install locally on a machine with a CUDA GPU.

Google Colab

Install & configure 
!pip install -q "NotesGenerator[gpu] @ git+https://github.com/saisritejakuppaEros/NotesGenerator.git#subdirectory=note_taker"
!apt-get install -y -qq ffmpeg imagemagick libsm6 libxext6 libgl1

from notesgenerator.colab_env import configure_colab_env
configure_colab_env()  # outputs → /content/runs/, fixes torch on Colab
Run on a video 
!notesgenerator --video "/content/cv.mp4" --output my_lecture
# → /content/runs/my_lecture/report/report.md
# → /content/my_lecture_report.zip  (auto-created)
Download the zip 
from google.colab import files
files.download("/content/my_lecture_report.zip")
Tip: Upload your lecture to /content/ in Colab, or pass a YouTube URL with --url instead of --video.

Local install

Requires Python 3.10+, CUDA GPU, ffmpeg, and ImageMagick.

From GitHub 
pip install "NotesGenerator[gpu] @ git+https://github.com/saisritejakuppaEros/NotesGenerator.git#subdirectory=note_taker"
Run 
notesgenerator --video lecture.mp4 --output my_lecture

After PyPI publish:

pip install "NotesGenerator[gpu]"

CLI usage

Command Description
notesgenerator --video FILE --output NAME Process a local video file
notesgenerator --url URL --output NAME Download from YouTube, then process
--data-dir PATH Root for runs/ and model caches (default: cwd or /content on Colab)
--no-zip Skip creating the report zip archive
--no-compress Skip ImageMagick PNG compression

Requirements

  • GPU: CUDA-capable GPU (T4 16 GB works with auto-tuned settings)
  • System: ffmpeg, ImageMagick (convert)
  • Disk: Model cache (~5–10 GB for Qwen3-VL-4B + Whisper)
  • RAM/VRAM: See GPU memory for T4 tuning

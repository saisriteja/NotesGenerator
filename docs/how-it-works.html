How it works

NotesGenerator turns a lecture video into a structured markdown report. This page walks through the end-to-end flow, the models involved, and what each folder under runs/ contains.

Quick overview

flowchart LR
    subgraph input["Input"]
        V[Local video .mp4]
        Y[YouTube URL]
    end

    subgraph prep["Prepare & parse"]
        P[00 Prepare]
        T[02 Whisper transcribe]
        S[03 Scene detect]
        K[04 Keyframes]
    end

    subgraph vision["Vision + merge"]
        C[05 VLM captions]
        A[06 Align]
        M[07 Merge]
    end

    subgraph report["Report"]
        R[09 Generate report]
        Z[10 Compress images]
        ZIP[Zip report/]
    end

    Y -->|01 Download| P
    V --> P
    P --> T --> S --> K --> C --> A --> M --> R --> Z --> ZIP

Final output: runs/<name>/report/report.md (+ images in report/attachments/, optional <name>_report.zip).

Entry point

CLI 
notesgenerator --video lecture.mp4 --output my_lecture
# or
notesgenerator --url "https://youtube.com/watch?v=..." --output my_lecture

run_pipeline.py configures the environment (model cache paths, Colab fixes), optionally downloads from YouTube, then executes all steps in order via run_lecture.py.

Full pipeline flow

flowchart TB
    START([notesgenerator CLI])

    START --> SRC{Input source?}

    SRC -->|YouTube URL| DL["01 Download<br/>yt-dlp + ffmpeg"]
    SRC -->|Local file| PREP

    DL --> PREP["00 Prepare<br/>copy video, extract 16 kHz audio"]

    PREP --> W["02 Transcribe<br/>faster-whisper"]
    W --> SC["03 Detect scenes<br/>PySceneDetect"]
    SC --> KF["04 Extract keyframes<br/>OpenCV midpoint PNG"]
    KF --> VLM["05 Caption slides<br/>Qwen3-VL + vLLM"]
    VLM --> AL["06 Align transcript<br/>map Whisper → scene windows"]
    AL --> MG["07 Merge<br/>scenes + captions + transcript"]
    MG --> RP["09 Generate report<br/>Qwen3-VL + vLLM text"]
    RP --> CM["10 Compress images<br/>ImageMagick optional"]
    CM --> ZIP["Zip report/ folder"]

    ZIP --> DONE([report.md ready])

Steps using ML models: transcription (Whisper), slide captioning (Qwen3-VL), and report writing (Qwen3-VL). Everything else is classical video/audio processing.

Models & tools

Step What runs Default GPU?
01 Download yt-dlp, ffmpeg — No
00 Prepare ffmpeg — No
02 Transcribe faster-whisper medium Yes
03 Detect scenes PySceneDetect threshold 35, min 4s No
04 Keyframes OpenCV midpoint frame No
05 Caption slides Qwen3-VL via vLLM Qwen/Qwen3-VL-4B-Instruct Yes
06–07 Align & merge Python — No
09 Generate report Qwen3-VL via vLLM same Qwen model Yes
10 Compress ImageMagick palette PNG No

Whisper (speech → text)

  • Library: faster-whisper
  • Default size: medium — override with --whisper-model large-v3
  • Output: transcript/whisper_segments.json

Qwen3-VL (vision + language)

  • Default: Qwen/Qwen3-VL-4B-Instruct
  • Override via QWEN_MODEL env var or configure_colab_env(model=...)
  • Loaded in-process with vLLM (Colab-friendly, no separate server)
  • Used twice: step 05 (slide captioning) and step 09 (report writing)
  • Weights cached under {data_root}/models/hub/

Step 09 — report generation

Report generation reuses the same Qwen3-VL model but runs several LLM phases:

flowchart TB
    IN["Input: merged/scenes_merged.json + transcript/whisper_segments.json"]

    IN --> P1["Phase 1 — Topic outline"]
    P1 --> P2["Phase 2 — Per-topic sections write → refine ×2"]
    P2 --> P3["Phase 3 — Merge + mindmap"]
    P3 --> P4["Coverage audit ×2 passes"]
    P4 --> OUT["report/report.md + topics/ + attachments/"]
File Purpose
report/topic_outline.jsonMajor topics with nested time segments
report/main_scenes.jsonKey slide scenes picked for figures
report/topics/topic_XX.mdIndividual topic write-ups
report/mindmap.mdConcept mind map

report/report.mdFinal merged report

Run folder layout

Each --output my_lecture creates runs/my_lecture/:

runs/my_lecture/
├── raw/
│   ├── video.mp4          # normalized lecture video
│   └── audio.wav          # 16 kHz mono for Whisper
├── transcript/
│   └── whisper_segments.json
├── scenes/
│   ├── scene_list.json
│   └── keyframes/scene_001.png
├── captions/
│   └── vlm_captions.json
├── merged/
│   ├── aligned_scenes.json
│   └── scenes_merged.json
├── report/
│   ├── report.md          # ← main deliverable
│   ├── topic_outline.json
│   ├── topics/
│   ├── attachments/
│   └── mindmap.md
└── pipeline_timing.json

Data & cache paths

Path Contents
{data_root}/runs/All pipeline outputs
{data_root}/models/hub/Hugging Face model cache
{data_root}/models/torch/PyTorch hub cache

data_root defaults to /content on Colab, otherwise the current working directory. Override with --data-dir or NOTE_TAKER_ROOT.

Note: Step 08 (Obsidian notes via 08_generate_notes.py) is not in the default pipeline. The main deliverable is report/report.md from step 09.

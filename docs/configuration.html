Configuration

CLI flags, environment variables, and GPU defaults for running NotesGenerator on Colab T4 or larger GPUs.

CLI flags

Flag Default Description
--video PATH — Local lecture video (.mp4)
--url URL — YouTube URL (downloads via yt-dlp)
--output NAME required Run folder name under runs/
--data-dir PATH cwd / /content Root for runs and model caches
--whisper-model SIZE medium Whisper model size (large-v3, etc.)
--vlm-batch-size N auto Batch size for step 05 slide captioning
--max-model-len N auto vLLM context window for report step
--gpu-mem FRACTION auto GPU memory fraction for vLLM
--no-zip off Skip zip archive creation
--no-compress off Skip ImageMagick PNG compression
--force-all off Re-run all cached pipeline steps

Environment variables

Variable Description
QWEN_MODEL Override default Qwen/Qwen3-VL-4B-Instruct
NOTE_TAKER_ROOT Same as --data-dir — root for runs and caches

GPU memory (T4 / Colab)

Step 09 loads Qwen3-VL with a context window (max_model_len). On a 16 GB T4, a 16k context needs ~2.25 GiB of KV cache that does not fit alongside ~8.7 GiB model weights — vLLM fails with a KV cache memory error.

The pipeline auto-detects your GPU and picks safe defaults:

GPU class max_model_len gpu_mem
T4 and other ≤16 GB / CC < 8 8192 0.90
A100, L4, etc. (24 GB+, CC ≥ 8) 16384 0.82

At startup you will see a line like:

GPU 'Tesla T4' (14.6 GiB, CC 7.5) → report step uses max_model_len=8192

Configuration cheat sheet

Whisper size 
notesgenerator --video lecture.mp4 --output run1 --whisper-model large-v3
VLM batch size (step 05) 
notesgenerator --video lecture.mp4 --output run1 --vlm-batch-size 4
Manual vLLM settings (T4) 
notesgenerator --video lecture.mp4 --output run1 --max-model-len 8192 --gpu-mem 0.90
Skip compression 
notesgenerator --video lecture.mp4 --output run1 --no-compress
Force re-run 
notesgenerator --video lecture.mp4 --output run1 --force-all
Custom Qwen model 
QWEN_MODEL=Qwen/Qwen3-VL-8B-Instruct notesgenerator --video lecture.mp4 --output run1
Colab 
from notesgenerator.colab_env import configure_colab_env
configure_colab_env()  # paths, torch fixes, cache → /content/models/

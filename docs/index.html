Turn lecture videos into markdown reports

NotesGenerator downloads or ingests a lecture video, transcribes speech, detects slide scenes, captions keyframes with a vision-language model, and writes a structured report with equations, diagrams, and a topic timeline.

Get started See the pipeline Open in Colab

Key features

End-to-end automation

One CLI command from YouTube URL or local .mp4 to report.md plus a downloadable zip.

Slide-aware vision

Scene detection and Qwen3-VL captioning extract equations, diagrams, and summaries from each keyframe.

Structured reports

Topic outline, per-topic sections, mind map, coverage audit, and TeX math — not just a raw transcript dump.

Colab-ready

vLLM runs in-process (no separate server). GPU memory defaults auto-tune for T4 vs A100.

Quick example

CLI 
notesgenerator --video lecture.mp4 --output my_lecture
# → runs/my_lecture/report/report.md
# → my_lecture_report.zip
YouTube 
notesgenerator --url "https://youtube.com/watch?v=..." --output my_lecture
Output: A markdown report with slide attachments, topic index, session timeline, and per-topic breakdowns. See Examples for sample output structure.
